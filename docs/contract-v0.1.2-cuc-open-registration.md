# 碰个面 MVP 增量契约 contract v0.1.2

> 状态：已确认
> 生效日期：2026 年 10 月 8 日
> 依赖契约：`contract-v0.1.1-auth-and-multi-request.md`
> 适用范围：中国传媒大学公开自助注册

## 1. 范围

- 第一阶段只开放中国传媒大学，学校代码固定为 `CUC`。
- 所有普通注册账号由服务端归属到 `CUC`，不接受客户端选择或覆盖学校。
- H5 展示“中国传媒大学”，不要求用户输入学校代码。
- 中国大陆手机号允许输入 11 位，服务端统一保存为 `+86` E.164 格式；已有 E.164 输入继续兼容。
- 注册成功后直接建立全局会话；退出后可使用同一手机号和密码重新登录。
- 本增量不开放 OPS 或 ADMIN 注册，不加入其他学校，不实现短信验证或找回密码。

## 2. 安全与上线边界

- 生产数据库只执行 migration，不执行测试 seed。
- `CUC` 学校不存在或不是 `ACTIVE` 时，注册必须停止并返回明确错误，不得回退到测试学校。
- 手机号唯一约束继续生效，重复注册返回冲突错误。
- 当前属于校园内测；正式大规模公开前接入手机号所有权验证，并复用于后续找回密码。

## 3. 验收

- [ ] 11 位中国大陆手机号可以注册，数据库保存为 `+86` E.164。
- [ ] 注册账号的学校固定为 `CUC`。
- [ ] 注册成功自动进入工作台，刷新后恢复同一账号。
- [ ] 退出后可以用 11 位手机号重新登录。
- [ ] 重复手机号注册被拒绝。
- [ ] 客户端无法通过构造请求注册到其他学校。
- [ ] 生产环境没有测试学校账号或 seed 数据。
